# 市民大道｜第一次評圖

市民高架沿線（淡水河堤—基隆路、南京西路—仁愛路）第一次評圖的文字、程式與展覽圖面。

## 內容

- `第一次評圖、展覽/`：展覽 PDF、十分鐘講稿、推導文本、圖面文字精簡稿、檔案統整
- `第一次評圖/`：分析程式、workflow 修訂指令等文字檔（目錄結構與原資料夾相同）
- `講稿文意.rtf`：講稿方向說明

## 沒有放進來的

原始資料約 10 GB，只收文字、程式和 100 MB 以下的展覽 PDF。以下沒有收錄：

- `.ai`、`.zip`、影像與快取、`99_桌面原始資料歸檔`、`unuse/` 舊版圖面
- 分析用資料（csv、geojson 等），所以這裡的程式無法直接重跑
- 稅籍原始資料
- 都市計畫書全文（內含陳情人姓名與地址）；內容請向臺北市都市發展局查詢

# 市民大道官方底圖參考

取得日期：2026-09-26。來源為臺北市三維地籍建物 GIS 公開場景所列服務。

- 座標系統：TWD97 / TM2 121，EPSG:3826，公尺。
- 查詢範圍：E 300975–307450、N 2770600–2771645，沿用既有四分幅包絡範圍；不代表市民大道全線。
- `parcels_twd97.esri.json`：官方地籍多邊形，ArcGIS JSON，不是 GeoJSON。
- `civic_official_parcels_reference.dxf`：地籍參考線，模型 1:1 公尺，附 200 m 圖示比例尺；共同重疊線以幾何聯集合併。地籍層不得直接當道路外緣或建物牆線。
- `property_polygons_twd97.esri.json`：登記產權多邊形，保留樓層與高度屬性；不同樓層不可全部壓平當建物外緣。
- `public_layer_sources.json`：官方公開場景所列服務來源；列出不代表全部已下載或可用。
- 各 `retrieval_report.json`：實際下載數及限制。

這些檔案是參考底圖，尚非逐段影像核對完成的離地 0.50 m 平面圖。產權界、地籍界、屋頂投影與地表實體外牆並非相同概念。未下載任何所有權人資料。

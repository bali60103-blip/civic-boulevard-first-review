## 不得誤用

REF_* 為獨立資料參考層。REVIEW_ROAD_UNVERIFIED 為舊候選線，只供比對。正式 CUT_*、EDGE_*、ROAD_MARKING 圖層保持空白，因尚無逐段核對後的新描圖。

精確重疊聯集只處理參考線的幾何重疊，沒有依距離強行刪掉相鄰但不同實體。資料來源之間的重線不得當成使用者要求已達成。

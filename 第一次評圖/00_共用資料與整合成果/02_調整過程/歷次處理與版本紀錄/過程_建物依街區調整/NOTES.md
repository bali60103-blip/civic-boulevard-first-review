# 巷道 → 街廓 → 建築

固定前版 ROAD_CLOSED 幾何與閉合旗標。以道路面及分隔島扣除後的陸域作概算街廓，再將所有建物限制在街廓內。本版不再保留侵入採用道路面的建物填色；採輪廓裁整，不是整棟搬移，也不是現況牆線校正。

街廓以資料工作範圍封閉，外圍包含人為範圍邊界；因此只放在 BLOCK_CLOSED_TOPOLOGY 關閉、不列印層，不冒充地籍線或實體路緣。列印的共用街廓／道路界由 ROAD_CLOSED 表示一次。

建物黑色填色透明度 40%；內院保持空白。BUILDING_CLOSED_EDIT 保存閉合可編輯輪廓，預設關閉且不列印，避免沿路共邊重畫。開啟此層即可選取整個建物外環／內環。原建物實體完整保存在 REF_BUILDINGS_BEFORE_BLOCK_CONSTRAINT 關閉參考層。

前版橙 L 圈改代表大幅概算修整的原衝突位置，而非尚未裁掉的填色；B、S、P、Q 延續原版待核。完全落在道路／分隔島的候選建物不顯示於新版填色，但仍可在參考層找回。每筆前後幾何和移除面積見 register.json。

本輪未新增衛星、街景或測量資料；固定的是既有模型巷道，不代表現場路寬已查證。人行道和高架結構仍沿用上一版的限制。圖面保持 A1 1:1000，A00 索引 1:10000。
